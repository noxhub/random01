# Pop-Up Places

Web AR prototype: snap any flat surface and a 3D character comes to life on it.

- Live: https://agreeable-grass-066b5e81e.5.azurestaticapps.net (Azure) or https://noxhub.github.io/random01/ — open in Safari on iPhone
- `index.html` — the app (capture a surface, pick a character and move, snapshot, places saved on the phone, share them with people nearby)
- `mural.mind` — tracking target for the orca mural demo
- `server/` — first piece of the shared backend, live at https://popup-places-api.azurewebsites.net (see `server/README.md`)

The site is served from the `gh-pages` branch.
